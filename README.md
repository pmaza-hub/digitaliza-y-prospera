# Digitaliza y Próspera

Sitio web estático de Digitaliza y Próspera, construido con HTML, CSS y JavaScript.

## Archivos

- `index.html`: página principal
- `styles.css`: estilos y diseño adaptable
- `script.js`: navegación, carrusel y enlaces de contacto
- `privacidad.html` y `terminos.html`: páginas informativas (borradores pendientes de completar y revisión)

## Vista local

Abre `index.html` en un navegador o sirve esta carpeta con cualquier servidor estático.
